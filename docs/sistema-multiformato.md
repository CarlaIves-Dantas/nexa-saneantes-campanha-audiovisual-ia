# NEXA — Sistema Multiformato

Este documento registra o padrão consolidado de adaptação audiovisual do case NEXA Saneantes.

## Formatos oficiais

### 16:9 — Master
Formato principal de produção. É a versão com maior área horizontal e concentra a composição audiovisual original.

### 9:16 — Reels / Shorts
Versão social vertical criada a partir de um layout dedicado, sem depender de crop agressivo do master.

Características:
- fundo grafite/preto fosco;
- identidade NEXA no topo;
- vídeo 16:9 preservado em área central;
- identificação de linha e assinatura visual na base;
- cortes manuais;
- frases completas;
- redução de duração para consumo em redes sociais.

### 4:5 — Feed
Versão para feed do Instagram, em 1080 × 1350.

A versão 4:5 segue o mesmo sistema visual do template 9:16, com adaptações proporcionais:
- mesma linguagem grafite/preto fosco;
- mesma identidade NEXA;
- vídeo principal preservado sem crop agressivo;
- área útil horizontal maior que no 9:16;
- faixas superior e inferior mais compactas;
- manutenção da hierarquia de marca, produto e linha.

A versão foi testada diretamente no Instagram e validada visualmente.

## Fluxo oficial

**MASTER 16:9 → CORTE SOCIAL → TEMPLATE 9:16 / TEMPLATE 4:5**

## Princípio de produção

> Criar para o formato principal, mas compor para sobreviver ao formato secundário.

## Regra operacional

1. Produzir e aprovar o master 16:9.
2. Criar um corte social com apenas os trechos finais aprovados.
3. Preservar frases completas e evitar cortes no meio da fala.
4. Inserir o corte em um template próprio para 9:16 ou 4:5.
5. Ajustar enquadramento, escala, textos e identidade por formato.
6. Regenerar apenas cenas críticas quando a adaptação não preservar produto, apresentadora ou informação essencial.

## Conclusão

O problema inicial de adaptação 16:9 para formatos sociais foi resolvido não por recorte automático, mas por um sistema de composição reutilizável. O mesmo conceito foi validado em 9:16 e 4:5, criando um fluxo multiformato replicável para futuras campanhas, incluindo a próxima peça técnica da linha industrial.
